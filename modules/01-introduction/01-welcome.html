About this course

In the Module PJDS 07082: Multimedia Project you work in a small team to build a web application, the Gallery, and to run it the way a professional software team would. You start from a shared skeleton project, make changes on your own laptop / PC, and release them to real servers on AWS.

The focus is on the whole path from an idea on your laptop to a running site. You collaborate through GitHub, review each other’s work, and deploy automatically to a test server and then a prod server.

What you’ll learn

By the end of this lesson you will be able to:

  • Clone your team’s repository and run the Gallery on your own laptop.
  • Set up and configure test and prod servers on AWS.
  • Use feature branches and pull requests to make changes without breaking the work of others.
  • Explain how a change moves from a laptop/PC to the test server and then to production.
  • Release a version by merging to main and tagging it, then check that it is live on the prod server.

How the course works

Your team works in one shared GitHub repository, and every change goes through a pull request.

Environment Where it runs Updated when
dev Your laptop You run it
test An AWS server A pull request is merged into develop
prod An AWS server A release tag is pushed on main

Some steps are done by every team member. Others are done once per team, with one person driving while the others watch and the driver changing between steps.

What you need

  • A GitHub account, with the invitation to your team repo accepted
  • JDK 17, Docker Desktop and Git on your laptop
  • Access to the AWS Academy course your lecturer has enrolled you in
  • An SSH client, such as the ssh command in PowerShell, Terminal or Git Bash

Where to start

Begin with the Build and deploy overview. It shows the whole process in one diagram and lists the seven steps you will follow.
