1. Clone the team repo and run it locally

Author

Mr. John Jennings

Who: every team member, on their own laptop. Goal: the Gallery skeleton running on your laptop, with its MySQL database running in Docker.

1.1 Check your tools

Open a terminal (PowerShell, Terminal or Git Bash) and run each check:

Tool Check Expect
JDK 17 java -version 17.x
Docker docker --version A version number, and Docker Desktop running
Git git --version A version number

You do not need Maven: the repo includes the Maven wrapper (mvnw), which downloads the right version itself.

1.2 Accept the invitation

Your lecturer has added you to your team’s repo on their GitHub account. Accept the invitation from the email GitHub sent you, or from https://github.com/notifications. Until you accept, the repo URL gives a 404.

1.3 Clone the repo

Use the URL your lecturer gives you in class. It looks like https://github.com/<lecturer>/<team-repo>.git.

  • IntelliJ
  • Command line
  1. File → New → Project from Version Control.
  2. Paste the URL and choose a folder.
  3. When asked, sign in with GitHub in the browser.
  4. Click Clone, then Trust Project.
  5. Bottom right, click the branch name (main) and choose origin/develop → Checkout.
git clone https://github.com/<lecturer>/<team-repo>.git
cd <team-repo>
git switch develop

The repo is private, so Git asks you to sign in. On Windows, a browser window opens: sign in to GitHub there. Do not type your GitHub password at a terminal prompt; GitHub rejects passwords for Git.

You work from develop, never main. main only changes at a release (step 6).

1.4 Start the database

From the repo folder:

docker compose up -d db

The first run downloads the MySQL image, which takes a minute. Then check it:

docker compose ps

The db service should show running (healthy). Confirm you can reach the gallery database:

docker compose exec db mysql -ugallery -pgallerypass -e "SHOW DATABASES;"

The list should include gallery. The warning about using a password on the command line is expected.

Note

The app does not use the database yet. It connects from week 3, when persistence is added. Starting it now means you meet any Docker problems this week rather than mid-sprint.

1.5 Run the app

  • IntelliJ
  • Command line

Open src/main/java/ie/tus/gallery/GalleryApplication.java and click the green ▶ next to main.

./mvnw spring-boot:run

In PowerShell, use .\mvnw.cmd spring-boot:run. On macOS or Linux, if you get Permission denied, run chmod +x mvnw once.

Open http://localhost:8080. Check:

These are dev-only accounts; they must never reach prod (step 7 explains).

Stop the app with Ctrl+C, or the red ■ in IntelliJ.

1.6 Run the build CI runs

./mvnw verify

(.\mvnw.cmd verify in PowerShell.) It compiles the app, runs its tests and packages it. If it ends with BUILD SUCCESS, your laptop builds the app exactly as the pipeline will.

1.7 Optional: run the whole stack in Docker

docker compose up --build

This builds the app’s Docker image from the Dockerfile and runs it next to MySQL, which is close to what the EC2 servers will do. Open http://localhost:8080, then stop it with Ctrl+C and run docker compose down.

Troubleshooting

Symptom Fix
Repository not found when cloning You have not accepted the invitation, or you are signed in to Git as a different GitHub account
Cannot connect to the Docker daemon Start Docker Desktop and wait until it says it is running
port is already allocated for 3306 Another MySQL is running on your laptop. Stop it, or change the left-hand port in docker-compose.yml for yourself only and do not commit that change
Port 8080 already in use An old run is still going. Stop it in IntelliJ, or close the terminal running it
Invalid source release: 17 Your terminal is using another JDK. Check java -version and set JAVA_HOME to a JDK 17
cannot read distributionUrl property .mvn/wrapper/maven-wrapper.properties is missing from the repo. Tell your lecturer
TipCheckpoint

App running at localhost:8080, db healthy in Docker, and mvnw verify green. Tell your team, and move on when everyone has reached this point.
